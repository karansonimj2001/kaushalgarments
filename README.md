## 🛒 Kaushal Traders – Local Trading Website

A client project designed and developed for Kaushal Traders, a local trading business.
The website was built to establish their digital presence, showcase products, and provide a user-friendly, responsive platform for customers.

## 🚀 Features

📱 Mobile Responsive – Works seamlessly across all devices

🛍️ Product Listings – On-page product showcase with clean UI

💬 WhatsApp API Integration – Direct customer inquiry option

⚡ Fast & Lightweight – Optimized for smooth browsing

🎨 Custom UI Design – Simple, modern, and business-focused

## 🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript

Hosting: GitHub Pages (with custom domain integration)

## 🌍 Live Website

🔗 www.kaushaltraders.com

## 📌 Project Highlights

Designed and delivered within client deadlines.

Focused on ease of navigation for a local audience.

Implemented WhatsApp integration for real-time product inquiries.

Custom domain successfully connected & deployed via GitHub Pages.
